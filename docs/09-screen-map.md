# 09. Экраны, состояния и правила отрисовки

Это спецификация для мобильного модуля внутри DDX, а не изображение действующего интерфейса. Прежние фейк-скрины покрывали только вход, три станции, ошибку штанги и результат; в них ошибочно был таймер. Они **не подтверждают** реализацию HELP, сети и 3D. Новый [интерактивный прототип](../prototype/bench-guide.html) показывает механику скамьи схематично; точный внешний вид FW-702 требует лицензированного ассета и проверки с реальным экземпляром.

| Экран / режим | Серверное состояние или источник | Видимые элементы | Действие / переход |
| --- | --- | --- | --- |
| Профиль → Инструкции | существующий каталог | поиск, производитель, карточка модели, пометка 3D при наличии | открыть гайд модели или карточку практики |
| Гайд из карточки модели | GET /v1/equipment-guides/{guideId} | вращаемая скамья, этапы, текст, видео | изучение не меняет игровую сессию; назад в каталог |
| Карточка «Смена» | GET /v1/shift, нет активной | цель и четыре блока прохождения без таймера | POST /sessions → Гантели |
| «Продолжить» | activeSessionId | текущий этап и сохранённый прогресс | GET /sessions/{id} → точный этап/шаг |
| Гантели | ACTIVE/DUMBBELLS | стойка, 6 гантелей, 3 секции 8/12/16 кг, счётчик 0…6 | полный ответ → BARBELL либо подсказка |
| Штанга | ACTIVE/BARBELL | гриф 20 кг, установленные 20+5 с каждой стороны, цель 77,5; блины 1,25/2,5/5/10, обе стороны и суммы | полный ответ → HELP либо ошибка асимметрии/массы |
| Помощь: вступление | PAUSED_HELP/HELP, индекс 0 | просьба персонажа показать регулировку; модель и кнопка «Начать со спинки» | открывает тот же шаг, не отправляя серверной команды |
| Спинка: фиксатор | HELP, индекс 0 | модель, подсвеченный Pull Pin, ракурс на орган управления, текст, 1/6 | выбор зоны и POST /help/act → индекс 1 |
| Спинка: движение | HELP, индекс 1 | клип подъёма/опускания, поворот, пауза, повтор, 2/6 | клип завершён + подтверждение → индекс 2 |
| Спинка: фиксация | HELP, индекс 2 | отпускание фиксатора, контроль фиксации, 3/6 | POST → индекс 3 |
| Сиденье: рычаг | HELP, индекс 3 | другой орган управления, ракурс под сиденьем, 4/6 | POST → индекс 4 |
| Сиденье: движение | HELP, индекс 4 | отдельный клип сиденья, 5/6 | клип завершён + POST → индекс 5 |
| Сиденье: фиксация | HELP, индекс 5 | отпускание рычага, 6/6 | POST → ACTIVE/EQUIPMENT |
| Зал сверху | ACTIVE/EQUIPMENT | план зала, 8 предметов: коврики, МФР, фитболы, кубы; четыре подписанные зоны | полный ответ → RESULT либо WRONG_ZONE |
| Результат | COMPLETED/RESULT | завершение, «Ещё раз», «Выбрать Smart Start» | новая сессия либо действующий экран записи |
| Закрытая сессия | ABANDONED/NONE или EXPIRED/NONE | объяснение, «Начать заново» | новый POST /sessions |
| Сеть недоступна | любой этап при наличии снимка | последний этап, черновик, метка «Нет сети» | локальный просмотр/перемещение; проверка заблокирована |
| Исход команды неизвестен | таймаут/5xx после POST | индикатор повторной проверки, без ложного успеха | повторить тот же ключ/тело, затем GET |
| Конфликт версии | 409 | предупреждение о другом устройстве | GET, серверный этап и индекс |
| 3D недоступен | ошибка ассета/рендера | видео/ключевые кадры, текст и кнопки органов управления | гайд доступен, игра проверяет те же шаги |
| Обновление клиента | 426 | штатный экран обновления | новые ответы недоступны |

## Правила отрисовки

- Полоса прогресса: «Гантели → Штанга → Помощь (0…6) → Инвентарь». В HELP серверный индекс — источник истины; анимация сама его не повышает.
- На экранах **нет обратного отсчёта**: семидневное истечение сессии проверяется сервером, но пользователь не проходит игру на скорость.
- Для каждого перетаскивания есть управление выбором предмета и зоны/стороны. Модель вращается жестом и кнопками смены ракурса; активная зона имеет текстовую кнопку. Клип можно повторять, а при reduced motion — видеть ключевые кадры.
- При неверной игровой попытке объекты остаются редактируемыми, `feedbackCode` показывается текстом. HTTP 400/409/426 — отдельные состояния, а не игровые ошибки.
- На iPhone захват блина даёт один градуированный отклик, фиксация — мягкое подтверждение. Отклик не служит единственным носителем информации.
- Кнопка Smart Start появляется только после COMPLETED. Бронирование и свободные места отображает действующий модуль DDX. Выход из игры не стирает сессию; явный отказ требует подтверждения.
