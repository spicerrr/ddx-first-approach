# «Первый подход»: переход от «Смены» к игровому онбордингу

**Статус:** новая продуктовая постановка; исходные документы `docs/00–13` сохраняются как историческая SA-спецификация и требуют поэтапной синхронизации. Это **не** утверждённая работа DDX TECH.

## Почему изменился продуктовый сценарий

Учебная «Смена» первоначально строилась вокруг роли дежурного тренера: раскладка гантелей, сборка штанги, помощь виртуальному посетителю в регулировке скамьи, сортировка инвентаря и переход к Smart Start.

Новая бизнес-гипотеза: новый клиент DDX может не обнаруживать своевременно инструкции и существующие бесплатные форматы адаптации. У DDX уже есть Smart Start и ознакомительная тренировка; задача не изобретать замену, а предложить понятный интерактивный вход в эти услуги.

**Новое позиционирование:** «Первый подход» — необязательная игра для знакомства нового участника с правилами зала и обращением с инвентарём. Игрок не становится дежурным тренером и не обучается обслуживать других.

**Основная метрика:** доля новых клиентов, фактически посетивших вводное занятие / Smart Start в первые 14 дней после предложения игры по сравнению с контрольной группой. Сам эффект не доказан. Infinity Plus не входит в бизнес-цель.

## Изменения бизнес-сценария

| Исходное | Новое |
|---|---|
| Игрок — дежурный тренер | Игрок — новый посетитель |
| Событие помощи другому посетителю | Самостоятельное знакомство с регулировкой скамьи |
| Результат → Smart Start | Памятка правил → Smart Start / ознакомительная тренировка при наличии права |
| Проверка клика на Smart Start | Отдельно: клик → запись → фактическое посещение |
| Игра в разделе инструкций | Гипотеза входа из онбординга + вторичный вход в инструкциях |
| Разовая мини-игра | Остаётся разовой, без платных/накопительных механик |

## Границы и условия

- Тарифы Light/Smart/Infinity/Infinity Plus получают одинаковый образовательный сценарий; paywall отсутствует.
- Игра не создаёт бронь и не меняет подписку.
- Правила оборудования проверяются у методиста/владельца контента.
- Штанга 77,5 кг в исходном кейсе — параметр учебного задания, не совет новичку по рабочему весу.
- Сервисные API и техника DDX неизвестны: все контракты — проектная спецификация.
- Эффективность игрового формата необходимо сравнивать с обычной информационной карточкой.
