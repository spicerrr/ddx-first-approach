# Первый подход

**Интерактивное знакомство с тренажёрным залом для DDX Fitness App**

«Первый подход» — концепция необязательной мини-игры для человека, который впервые приходит в фитнес-клуб. Вместо длинной инструкции пользователь разбирает четыре короткие ситуации: куда убрать гантели, как симметрично расположить диски на виртуальной штанге, что проверить у незнакомой скамьи и где хранится мелкий инвентарь. Ошибки можно исправить; прохождение не влияет на доступ к клубу.

Проект рассматривает, как такую механику можно встроить в мобильное приложение фитнес-сети — от пользовательского сценария до модели данных и API. Это самостоятельная концепция, **не официальный продукт DDX**.

## Где это происходит

**DDX Fitness** — сеть фитнес-клубов, работающая по подписке. У сети есть мобильное приложение: через него участники, в частности, записываются на тренировки.

Клуб предлагает способы познакомиться с оборудованием с помощью тренера:

- **Smart Start** — 30-минутные занятия в небольших группах (до 10 человек), посвящённые отдельным мышечным группам, технике и тренажёрам. Они включены в подписку на всех тарифах.
- **Ознакомительная тренировка** — отдельное занятие с тренером: знакомство с зонами клуба, оборудованием и возможностями адаптации.

[О Smart Start на сайте DDX](https://www.ddxfitness.ru/smart-start/) · [О тренировках и условиях подписки](https://www.ddxfitness.ru/faq/) · [Об ознакомительной тренировке](https://www.ddxfitness.ru/group-training/3076/)

**Игра не заменяет эти занятия.** Она предлагает короткое знакомство с базовыми ситуациями и позволяет перейти к уже существующим форматам помощи.

## Сценарий

1. **Предложение.** При подходящем моменте знакомства с приложением новый участник видит необязательный вход в игру. Можно сразу открыть информацию о Smart Start или пропустить игру.
2. **Четыре станции.** Пользователь взаимодействует с виртуальными предметами и проходит короткие проверки.
3. **Обратная связь.** Неверный выбор объясняется; правильно выполненные действия сохраняются.
4. **Завершение.** После четырёх станций появляется памятка и переход к Smart Start или ознакомительной тренировке. **Для перехода к занятиям завершать игру не требуется.**

| Станция | Что делает пользователь |
|---|---|
| **01 · Гантели** | Возвращает три пары гантелей 8, 12 и 16 кг в подписанные ячейки стойки |
| **02 · Штанга** | Располагает виртуальные диски по 5 и 10 кг симметрично с обеих сторон |
| **03 · Скамья** | Выбирает шесть логических проверок перед использованием незнакомого оборудования |
| **04 · Инвентарь** | Распределяет восемь предметов между четырьмя зонами хранения |

> Сценарий моделирует решения внутри игры, а не обучает безопасной работе с конкретной моделью тренажёра. Условные веса не являются тренировочной рекомендацией.

## Зачем это исследовать

Вопрос проекта не в том, существуют ли у DDX способы адаптации: **они уже есть**. Вопрос — всегда ли новый участник замечает подходящую помощь и есть ли смысл дополнить существующую навигацию интерактивным знакомством.

Это **гипотеза, а не установленная проблема**. Данных о том, сколько новичков не находят вводные занятия, нет. Возможно, достаточно заметной карточки с объяснением и ссылкой на запись; игра должна показать дополнительную ценность по сравнению с таким простым решением.

Поэтому в проекте отдельно рассматривается сравнение трёх вариантов: текущий онбординг, информационная карточка и интерактивная игра. Значимый результат — **фактическое посещение** вводного занятия, а не количество игровых завершений или кликов.

### Запустить локально

Из корня репозитория:

```bash
python3 -m http.server 8080
```

Открыть: `http://localhost:8080/first-set/demo/`.

Сервер здесь используется **только для раздачи статических файлов**. Прототип не обращается к DDX, не авторизует пользователей и не бронирует занятия.
