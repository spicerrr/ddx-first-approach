# Первый подход

**Интерактивное знакомство новичка с тренажёрным залом DDX Fitness**

Самостоятельный учебно-портфельный проект: игровой онбординг для существующего DDX Fitness App. У DDX уже есть бесплатные Smart Start и ознакомительные тренировки, но их наличие не гарантирует, что каждый новый клиент своевременно узнает о них. Здесь исследуется гипотеза о более доступном знакомстве с правилами зала и услугами адаптации. Конверсия и бизнес-эффект пока не подтверждены.

Игра моделирует четыре ситуации: возврат гантелей, подготовку штанги, безопасное знакомство с настройкой скамьи и размещение инвентаря. После завершения пользователь видит пояснения и предложение воспользоваться существующей программой знакомства с тренером. Никакие платные функции и тарифные изменения для этого не нужны.

## Задача и границы

Проверить, может ли короткая интерактивная игра помочь новым участникам понять правила обращения с инвентарём и воспользоваться уже существующими услугами адаптации. Целевой продукт — мобильное приложение DDX Fitness; прототип выполнен в браузере и не подключён к приватным сервисам компании.

**Зона моей работы:** исследование публичных материалов DDX, продуктовая постановка, бизнес- и системные требования, проектирование состояний, контрактов и данных, сценарии приёмки, пользовательский прототип и модель проверки гипотезы.

**Статус:** учебная концепция НИУ ВШЭ, доработанная как самостоятельный аналитический кейс. Не является заказом, разработкой или официальной инициативой DDX Fitness / DDX TECH. Фактические внутренние интерфейсы компании неизвестны.
