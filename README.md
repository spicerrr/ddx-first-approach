# Первый подход · DDX Fitness

**Игровой онбординг нового участника фитнес-клуба.** Проект вырос из курсовой игры «Смена» по интерактивным движкам НИУ ВШЭ. После изучения публичных материалов DDX сценарий переработан как необязательное знакомство с правилами клуба и услугами адаптации.

> Независимый учебный и портфельный проект. Не является разработкой, заказом или внутренней документацией DDX Fitness / DDX TECH.

## Задача

DDX предлагает Smart Start, ознакомительные тренировки и инструкции. Проверяем гипотезу, что часть новых клиентов не обнаруживает эти ресурсы вовремя. Игра знакомит с возвратом инвентаря, симметричным размещением дисков и безопасным обращением с регулируемым оборудованием, затем предлагает перейти к действующим вводным занятиям. Доля неосведомлённых клиентов и влияние на удержание пока неизвестны.

## Границы инициативы

- Одна законченная игровая сессия и четыре эпизода; без наград, ежедневных заданий и монетизации.
- CTA ведёт к существующим Smart Start или ознакомительной тренировке, если услуга доступна; игра не создаёт бронирование.
- Прохождение не является допуском к оборудованию и не заменяет практический инструктаж.
- У DDX публично не раскрыты внутренние API и команды. Системные контракты в кейсе являются предложениями.
