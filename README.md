# Первый подход

**[Открыть прототип](https://spicerrr.github.io/ddx-first-approach/)**

DDX Fitness помогает новым участникам освоиться в зале через ознакомительные тренировки и Smart Start. «Первый подход» проверяет гипотезу о другой части первого визита. Новичку может быть сложно самостоятельно разобраться со свободными весами, регулируемой скамьёй и хранением инвентаря. Масштаб этого барьера требует проверки на клиентах DDX. [Smart Start](https://www.ddxfitness.ru/smart-start/) · [Ознакомительная тренировка](https://www.ddxfitness.ru/group-training/3076/)

Предложение для «Точки старта» в DDX Fitness App — необязательный игровой маршрут. Человек пробует действия на снарядах, получает подсказки по ситуации и может отдельно выбрать помощь тренера.

**Главная → Точка старта → Первый подход → Маршрут → четыре станции → Итоги**

| Станция | Что делает участник |
| --- | --- |
| Гантели | Возвращает шесть гантелей по 8, 12 и 16 кг на парные места |
| Штанга | Собирает 80 кг с грифом 20 кг, равной массой по сторонам и двумя закрытыми замками |
| Скамья | Подстраивает спинку и сиденье под контуры на модели |
| Инвентарь | Убирает восемь предметов, оставшихся на полу. Пять из тринадцати предметов уже на местах |

[Бизнес-анализ](first-set/ba/README.md) и [системный анализ](first-set/sa/README.md) описывают проектное предложение и условия его проверки. [Контракт сценария](first-set/sa/contracts/scenario-v2.sample.json) задаёт правила, которые исполняет браузерный прототип. [Схема аналитики](first-set/sa/contracts/events.schema.json) описывает события интерфейса.

React, TypeScript, Three.js и Vite используются в веб-прототипе для демонстрации механик на GitHub Pages. Выбор стека мобильной реализации остаётся за командой DDX.

## Запуск

Требуется Node.js 24.

```bash
cd first-set/demo
npm ci
npm run dev
```

[Управление, сборка и проверки](first-set/demo/README.md).

Самостоятельный проектный кейс. Размещение в приложении DDX, состав аудитории и эффект проверяются при согласовании пилота.
