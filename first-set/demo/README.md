# Интерактивный прототип «Первый подход»

[В проект](../../README.md) · [Бизнес-анализ](../ba/README.md) · [Системный анализ](../sa/README.md)

Интерактивный макет мобильного сценария «Первый подход». На главной DDX Fitness карточка «Впервые в зале?» предлагает подготовиться к первой тренировке. На старте можно открыть маршрут из четырёх станций или перейти к занятиям с тренером. На экране занятий есть ссылки на расписание ознакомительных тренировок по клубам и на занятия Smart Start. На широком экране макет масштабируется целиком. Внутренний размер рамки iPhone 17 составляет 402 × 874 CSS-пикселя.

## Запуск

Используй Node.js 24. Из корня репозитория:

```bash
cd first-set/demo
npm ci
npm run dev
```

Открой адрес, который Vite напечатает в терминале (обычно `http://localhost:5173/`).

```bash
npm run build
npm run preview
```

Готовые файлы лежат в `dist/`. Адрес предварительного просмотра включает путь `/ddx-first-approach/`.

## Один маршрут

- **Гантели.** Определи свободные места по маркировке соседних пар. На верхней полке веса 2, 4, 6 и 8 кг, на нижней — 10, 12, 14 и 16 кг. Вес растёт слева направо, места для пары идут подряд.
- **Штанга.** Пустой гриф весит 20 кг. Собери 80 кг с равной массой дисков с обеих сторон, затем поставь и защёлкни оба замка. Подойдёт, например, 20 + 10 кг слева и 10 + 5 + 5 + 5 + 5 кг справа. После проверки сцена показывает массу на обеих сторонах, состояние замков и совет набирать вес парами.
- **Скамья.** Тренер предлагает настроить сначала спинку, затем сиденье. Удерживай фиксатор одним пальцем, другим совмещай подушку с бирюзовым контуром. Положение засчитывается после отпускания фиксатора. Кнопка «Показать приём» открывает анимацию для текущей детали поверх модели и сохраняет её положение и ракурс. После обеих настроек открывается свободный режим и кнопка «К инвентарю».
- **Инвентарь.** Верни 13 предметов на места. Для дисков от 5 до 25 кг есть штыри с маркировкой, для резинок — боковые крючки, для ковриков, блоков и роллов — полки стеллажа. Предмет можно перетащить или выбрать касанием и затем нажать на место хранения.

Возьми диск на штанге или в лотке. При установке диск скользит от края втулки к собранному набору. На установленном замке нажми рычажок, чтобы защёлкнуть его. Перед снятием сначала открой замок.

При установке предметов звучат короткие сигналы. Звук можно выключить через «?». На устройствах с поддержкой [Vibration API](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/vibrate) посадка сопровождается вибрацией, а у дисков разной массы различается импульс.

Клавиатура поднимает предмет пробелом или Enter. Клавиша Tab переводит фокус к месту назначения. Пробел или Enter завершает перемещение, Escape отменяет выбор. На скамье можно удержать пробел и изменить наклон стрелками либо отвести фиксатор мышью и продолжить движение с зажатой кнопкой.

Внутри игры можно вернуться на карту маршрута и продолжить текущую попытку. При подтверждённом выходе или перезагрузке браузер помнит завершённые станции. При новом входе открывается первая незавершённая. После четырёх станций игра выбирает одну контрольную ситуацию, а затем ведёт к итогам.

## Код и графика

- [Правила](src/engine/game.ts) используют порядок станций из [контракта 1.0](../sa/contracts/scenario-v1.sample.json). [Уровни подсказок](src/engine/hints.ts) и события хранятся в памяти. В браузере сохраняется только количество завершённых станций.
- [Экраны](src/ui/screens.tsx) и [игровые сцены](src/ui/gym.tsx) построены на React и TypeScript. В [наборе графики](public/art/) лежат растровые изображения стойки, гантелей с маркировкой, грифа, дисков и замков. При перетаскивании подсветка показывает область под удерживаемым предметом.
- [Станция скамьи](src/ui/bench.tsx) управляет четырьмя анимациями [учебной модели GLB](public/art/bench.glb). Ресурс загружается перед станцией. При сбое можно продолжить на интерактивной схеме.

## Проверки

```bash
npm test
npm run build
npx playwright install --only-shell chromium
npm run test:e2e
```

Playwright проходит собранный маршрут через интерфейс, проверяет переходы, подсказки, восстановление прогресса и резервную схему скамьи. Покрыты клавиатура, мышь и сенсорные жесты. Вёрстка проверяется на ширинах 320, 375, 402, 430, 768 и 1440 px. Снимки сохраняются в `test-results/`. При необходимости можно передать путь к системному Chromium через `PLAYWRIGHT_CHROMIUM_PATH`.

## GitHub Pages

Для первого запуска выбери [Settings → Pages](https://github.com/spicerrr/ddx-first-approach/settings/pages) → **Source: GitHub Actions**. [Рабочий процесс публикации](../../.github/workflows/deploy-pages.yml) работает из `main`, собирает приложение, проверяет его и публикует папку `dist/`. Браузерные снимки сохраняются в артефакте `browser-checks` соответствующего запуска.
