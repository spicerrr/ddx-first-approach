# Интерактивный прототип

[← Первый подход](../../README.md) · [Продуктовая постановка](../ba/README.md) · [Системная спецификация](../sa/README.md)

Это браузерная модель четырёх станций «Первого подхода». Она позволяет попробовать задания и проверить сообщения об ошибках, сохранение локального прогресса и переход к информации о существующих занятиях DDX.

**Что можно сделать:** расставить три пары гантелей, собрать симметричную виртуальную штангу, пройти шесть проверок обращения со скамьёй и распределить восемь предметов инвентаря. Ошибочное действие сопровождается объяснением. К Smart Start можно перейти **без завершения** игры.

## Как открыть

Из корня репозитория выполнить:

```bash
python3 -m http.server 8080
```

Открыть в браузере `http://localhost:8080/first-set/demo/`.

Кнопка «Начать заново» очищает игровой прогресс. При повторном открытии страницы он восстанавливается из `localStorage` текущего браузера (ключ `first-approach-interactive-v2`).

## Исходные файлы

- [`index.html`](index.html) — разметка оболочки.
- [`style.css`](style.css) — адаптивные компоненты и состояния.
- [`logic.js`](logic.js) — правила четырёх станций, локальные события и сохранение.
- [`test-logic.mjs`](test-logic.mjs) — автоматические проверки игровых переходов.

**Это не подключённое к DDX приложение.** Здесь нет работающего игрового сервера, серверной авторизации, реального расписания или бронирования. Контракт будущего серверного взаимодействия, обработка сетевых повторов и модель данных находятся в [SA](../sa/README.md).
