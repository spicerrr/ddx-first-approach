# Браузерный прототип «Первый подход»

[Проект](../../README.md) · [Бизнес-анализ](../ba/README.md) · [Системный анализ](../sa/README.md)

На главной DDX нажми баннер **«Точка старта»** между историями и календарём. На карточке **«Первый подход»** выбери **«Открыть маршрут»**, затем **«Начать»**. Когда на четвёртой станции убран последний предмет, появятся два варианта продолжения в клубе. Кнопки **«Выбрать занятие Smart Start»** и **«Выбрать время с тренером»** открывают соответствующие расписания DDX в новой вкладке. Итоги остаются открытыми.

| Станция | Сценарий |
| --- | --- |
| Гантели | Подбери места по весу для пар 8, 12 и 16 кг |
| Штанга | Собери 80 кг с грифом 20 кг, равной массой дисков по сторонам и двумя закрытыми замками. Например, 20 + 10 кг слева и 10 + 5 + 5 + 5 + 5 кг справа. После проверки видны вес по сторонам и состояние замков |
| Скамья | Подстрой сначала спинку, затем сиденье. Регулировка засчитывается при отпускании фиксатора в нужном положении. Показ приёма сохраняет ракурс и положение модели |
| Инвентарь | На старте пять предметов стоят на местах. Убери три диска и пять остальных предметов. Резинки вешаются сбоку, коврики разворачиваются и складываются на нижней полке |

При переходе на карту текущая попытка остаётся в памяти. После подтверждённого выхода или перезагрузки браузер восстанавливает завершённые станции. Если нужно заново зайти на инвентарь, при запуске новой попытки генерируется другая выборка по тем же правилам. Случайная выборка может повториться.

## Управление

- Предметы перетаскиваются мышью или пальцем. У гантелей и инвентаря также можно выбрать предмет и нажать на место размещения.
- Для клавиатуры пробел или Enter выбирает предмет, Tab переводит фокус между местами. Пробел или Enter подтверждает место, Escape отменяет выбор.
- На скамье мышью отведи фиксатор и продолжай движение с зажатой кнопкой. На сенсорном экране удерживай фиксатор одним пальцем, вторым двигай подушку. На клавиатуре удерживай пробел и меняй положение стрелками. Подсказки раскрывают порядок по мере работы.
- Звук выключается через «?». Вибрация зависит от поддержки устройства. При уменьшенном движении укладка происходит сразу, а показ регулировки использует статичный кадр.

## Запуск

Требуется Node.js 24. Из корня репозитория:

```bash
cd first-set/demo
npm ci
npm run dev
```

Открой адрес из вывода Vite.

```bash
npm test
npm run build
npx playwright install --only-shell chromium
npm run test:e2e
```

Собранный макет лежит в `dist/`. Для предварительного просмотра выполни `npm run preview` и открой путь `/ddx-first-approach/`. На широком экране макет использует область 402 × 874 CSS-пикселя.

## Реализация

- [Правила](src/engine/game.ts) исполняют [сценарий 2.0](../sa/contracts/scenario-v2.sample.json). [Генератор инвентаря](src/engine/inventory.ts) принимает источник случайности и выполняется при старте попытки.
- React и TypeScript задают экран и состояние. Three.js отрисовывает [скамью](src/ui/bench-view.tsx). Vite собирает веб-версию. Стек относится к прототипу на GitHub Pages.
- Модули станций и GLB-модель загружаются по мере прохождения. При сбое модели остаётся интерактивная схема. При сбое игровой сцены можно вернуться в «Точку старта».
- [События интерфейса](src/engine/analytics.ts) можно наблюдать в браузере через `first-approach-analytics`. События не отправляются по сети.
- Playwright проверяет четыре станции, восстановление, подсказки, случайную раскладку, мышь, клавиатуру и сенсорную эмуляцию. Браузерные снимки сохраняются в `test-results/`.

[Публикация](../../.github/workflows/deploy-pages.yml) проверяет сборку и выкладывает её из `main` на GitHub Pages.
