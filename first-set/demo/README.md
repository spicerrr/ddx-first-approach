# Первый подход · интерактивная демонстрация

**Неофициальный учебный прототип для DDX Fitness App.** Четыре игровые станции: гантели, штанга, скамья, инвентарь. Действия объясняют правила клуба; финальный экран ведёт к демонстрационным CTA Smart Start и ознакомительной тренировки. Настоящие записи не создаются.

## Запуск

Откройте `index.html` в браузере. Сборка и backend не требуются. Состояние сохраняется через `localStorage` в текущем браузере; для обнуления выберите «Начать заново».
