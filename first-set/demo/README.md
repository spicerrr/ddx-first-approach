# Интерактивный прототип «Первый подход»

[В проект](../../README.md) · [Бизнес-анализ](../ba/README.md) · [Системный анализ](../sa/README.md)

Интерактивный макет мобильного сценария «Первый подход». На широком экране он отображается внутри рамки смартфона, на телефоне занимает экран устройства. Тренер проводит инструктаж, затем игрок проходит четыре станции. Переход к вводным занятиям доступен с главной и во время задачи.

## Запуск

Используй Node.js 24. Из корня репозитория:

```bash
cd first-set/demo
npm ci
npm run dev
```

Открой адрес, который Vite напечатает в терминале (обычно `http://localhost:5173/`).

```bash
npm run build
npm run preview
```

Готовые файлы лежат в `dist/`. Адрес предварительного просмотра включает путь `/ddx-first-approach/`.

## Один маршрут

- **Гантели.** Перетаскивай разбросанные снаряды на физическую стойку. Цифры нанесены на торцы. В каждом кармане стоят две гантели одного веса.
- **Штанга.** Стартовые 60 кг складываются из грифа 20 кг и двух дисков по 20 кг. Для зачёта нужны 80 кг, одинаковый набор дисков с обеих сторон и два замка. Подходит по диску 10 кг или по два диска 5 кг с каждой стороны. Учебный вес складывается из массы дисков и грифа.
- **Скамья.** Освободи каждую подушку, подними её по стрелке и проверь фиксацию. Спинка и сиденье регулируются по очереди. Вращай модель перетаскиванием и приближай щипком. Те же шаги доступны кнопками под подсказкой.
- **Инвентарь.** Перетащи восемь предметов с пола на обозначенные места хранения.

Возьми диск прямо на штанге или в лотке и перетащи его к месту назначения. Первым снимается крайний диск. Замок снимается тем же жестом. При начале движения диски 5, 10 и 20 кг вызывают разные короткие импульсы на устройствах с поддержкой [Vibration API](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/vibrate). В сцене положение предмета и подсветка показывают результат перетаскивания.

Клавиатура поднимает предмет пробелом или Enter. Клавиша Tab переводит фокус к месту назначения. Пробел или Enter завершает перемещение, Escape отменяет выбор.

Переходы к маршруту и информации о занятиях сохраняют текущее состояние в открытом прохождении. Выход на главную, закрытие или перезагрузка страницы начинают чистое прохождение.

## Код и графика

- [Правила](src/engine/game.ts) и [сборка штанги](src/engine/barbell.ts) работают в памяти. Сценарий макета 1.2 использует порядок станций из [контракта 1.0](../sa/contracts/scenario-v1.sample.json). События прохождения остаются в памяти и очищаются вместе с игровым состоянием.
- [Экраны](src/ui/screens.tsx) и [игровые сцены](src/ui/gym.tsx) построены на React и TypeScript. В [наборе графики](public/art/) лежат растровые фон зала, портрет, отдельные гантели с маркировкой, гриф, диски и замки. Подсветка обозначает области, куда можно перенести предмет.
- [Станция скамьи](src/ui/bench.tsx) управляет четырьмя анимациями [учебной модели GLB](public/art/bench.glb). Наклоны 30° для спинки и 12° для сиденья заданы для упражнения. Механизм конкретной клубной скамьи можно уточнить у тренера.

## Проверки

```bash
npm test
npm run build
npx playwright install --only-shell chromium
npm run test:e2e
```

Playwright открывает собранную версию по пути GitHub Pages. Он проходит игру через интерфейс, проверяет ошибки, установку и снятие дисков и замков, чистое состояние при выходе и перезагрузке, клавиатуру, мышь и сенсорное перетаскивание. Вёрстка проверяется на ширинах 320, 375, 390, 430, 768 и 1440 px. Снимки сохраняются в `test-results/`. При необходимости можно передать путь к системному Chromium через `PLAYWRIGHT_CHROMIUM_PATH`.

## GitHub Pages

Для первого запуска выбери [Settings → Pages](https://github.com/spicerrr/ddx-first-approach/settings/pages) → **Source: GitHub Actions**. [Рабочий процесс публикации](../../.github/workflows/deploy-pages.yml) работает из `main`, собирает приложение, проверяет его и публикует папку `dist/`. Браузерные снимки сохраняются в артефакте `browser-checks` соответствующего запуска.
