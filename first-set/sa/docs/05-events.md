# 05 · Product events & attribution

| Событие | Владелец | Смысл |
|---|---|---|
| onboarding_offer_exposed | Клиент | Показ предложения |
| game_session_started | Предлагаемый игровой сервер | Создание сессии |
| game_stage_completed | Игровой сервер | Завершение этапа |
| game_session_completed | Игровой сервер | Завершение всех этапов |
| intro_cta_clicked | Клиент | Попытка перехода к записи |
| intro_booking_confirmed | Существующая запись | Бронирование подтверждено |
| intro_attendance_confirmed | Существующая система | Посещение действительно состоялось |

Клик не равен бронированию, а бронирование — посещению. Для атрибуции необходимы согласованный идентификатор пользователя, экспериментальная группа, источник перехода и период наблюдения. Имена событий в сервисах DDX неизвестны.

Основная метрика BA — фактическое участие в вводном занятии в пределах заданного окна. Измерение игры без внешнего подтверждения посещения не доказывает эту бизнес-гипотезу.
