# Первый подход — бизнес-анализ

**Зачем DDX может понадобиться игровое знакомство новичков с клубом.**

Портфельная концепция, развившаяся из учебного проекта НИУ ВШЭ; не является внутренним проектом DDX. Компания уже предоставляет Smart Start и ознакомительные занятия. Мы рассматриваем гипотезу, что некоторым новичкам трудно вовремя найти информацию и воспользоваться существующей адаптацией. Доля таких клиентов не установлена.
