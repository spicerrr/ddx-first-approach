# Бизнес-анализ «Первого подхода»

## Бизнес-контекст и гипотеза

DDX Fitness предлагает новичкам 30-минутные занятия Smart Start в мини-группе и 55-минутную ознакомительную тренировку с персональным тренером. В первом случае тренер показывает упражнения и помогает с техникой. Во втором участник знакомится с зонами своего клуба и пробует тренировку с тренером. [Smart Start](https://www.ddxfitness.ru/smart-start/) · [Ознакомительная тренировка](https://www.ddxfitness.ru/group-training/3076/)

Гипотеза проекта — часть новых участников испытывает неопределённость перед самостоятельными действиями в зоне свободных весов. Например, человек не знает, как ориентироваться на гантельной стойке или как регулировать скамью. Частота таких ситуаций, группы с повышенным барьером и связь с первым посещением требуют внутренних наблюдений DDX.

Предлагается необязательная игра внутри «Точки старта». Участник пробует размещать снаряды и готовить оборудование. После четвёртой станции он видит, что сможет сделать на каждом из двух занятий, и может сразу перейти к расписанию. Бизнес-цель этого перехода — запись участника на первую тренировку в клубе.

| Сторона | Потребность |
| --- | --- |
| Новый участник | Понять, с каких самостоятельных действий начать. При желании выбрать помощь тренера |
| Команда клиентского опыта | Измерить барьер в первых визитах и проверить изменение уверенности после знакомства со сценами |
| Команда приложения | Разместить функцию в существующем пути клиента и контролировать влияние загрузки на основные действия |
| Тренеры и руководители клубов | Подтвердить реалистичность ситуаций и правил хранения, сохранив текущую организацию работы |

## Цели и способ проверки

| ID | Цель | Критерий оценки |
| --- | --- | --- |
| BG-01 | Снизить неопределённость перед самостоятельными действиями в свободных зонах | Изменение ответов до и после знакомства. Пример вопроса — насколько понятно, как определить место пары гантелей |
| BG-02 | Проверить дополнительную ценность игрового формата | Сравнение игры со статической памяткой того же содержания на сопоставимой аудитории. Оценка короткой ситуации проводится в исследовании |
| BG-03 | Увеличить долю новых участников, записавшихся на Smart Start или ознакомительную тренировку | В пилоте сравнить долю участников с подтверждённой записью среди всех участников каждого варианта за одинаковое окно. Посещение по этой записи отслеживать отдельным шагом |
| BG-04 | Сохранить доступность и быстродействие основных функций приложения | Проверка времени открытия основных экранов, доступности пропуска и работы навигации до пилота и во время него. Пороги определяются по фактической базе DDX |
| BG-05 | Сохранить текущую организацию работы сотрудников | Сопровождение игры обходится без действий тренера или администратора по каждой игровой попытке. Оценить обращения и объём работы по поддержке |

Внутри игрового пути измеряется доля завершивших маршрут, которые затем открыли расписание, с разбивкой по выбранному формату. Переходы из обычных разделов приложения учитываются отдельно. Для оценки эффекта пилота нужны сопоставимые группы, согласованное окно наблюдения и подтверждения записи и посещения из штатных систем DDX.

## Функциональные требования

| ID | Наблюдаемое поведение | Цель |
| --- | --- | --- |
| FR-01 | Под историями перед календарём на главной расположен баннер «Точка старта». Он открывает раздел с карточкой «Первый подход» и входом на карту | BG-01, BG-04 |
| FR-02 | Маршрут состоит из четырёх последовательных станций. Карта показывает текущую и завершённые станции. Внутри игры можно продолжить текущую попытку после возврата с карты | BG-01, BG-02 |
| FR-03 | Пользователь возвращает гантели по парам, собирает штангу по условиям задания и настраивает спинку и сиденье скамьи | BG-01 |
| FR-04 | В инвентаре пять предметов уже на местах. На полу остаются три диска и пять предметов остальных категорий. Интерфейс показывает объём оставшейся работы | BG-01, BG-02 |
| FR-05 | Тренер сначала формулирует задачу. После ошибки или запроса он даёт подсказку, её подробность зависит от действий по данному правилу. После исправления реплика учитывает результат | BG-01, BG-02 |
| FR-06 | После выхода или перезагрузки доступны завершённые станции и вход в первую незавершённую. Итоги показываются после четвёртой станции | BG-01, BG-04 |
| FR-07 | После четвёртой станции показаны два формата, длительность и содержание каждого. Любой вариант за одно нажатие открывает своё расписание. Можно вернуться в «Точку старта» | BG-01, BG-03, BG-05 |
| FR-08 | Для оценки пилота различаются показ предложения, запуск, этапы маршрута, помощь, завершение и переход к занятиям | BG-02, BG-03 |

## Бизнес-правила

- Попытка инвентаря начинается с двух дисков на штырях и трёх предметов из трёх разных категорий. Как минимум один предмет каждой категории остаётся на полу.
- Предмет, изначально стоящий на месте, учитывается в корректности сцены. Пользовательским действием считается принятое размещение предмета, который был на полу.
- Завершение игры означает успешное прохождение четырёх виртуальных задач. Результат описывает работу в симуляции.
- Smart Start и ознакомительные занятия остаются доступными независимо от прохождения. Их расписание и запись принадлежат существующим каналам DDX.

## Ограничения

| ID | Ограничение | Следствие |
| --- | --- | --- |
| NFR-01 | Модуль изолирован от основных функций приложения | Игра загружается по входу, отказ игровой сцены позволяет вернуться в «Точку старта» |
| NFR-02 | Существенная обратная связь доступна без звука | Результат виден в сцене и в репликах. Учитываются подходящие способы ввода и настройка уменьшенного движения |
| NFR-03 | Пользователь выбирает объём помощи | Подсказки запрашиваются вручную или уточняются после действия. Освоение в своём темпе доступно без участия сотрудника |

До пилота нужны данные о моменте и критериях показа, различиях между клубами, исходной частоте ошибок, базовых показателях первых визитов и организационных затратах. Условия допуска, метрики и владельцы данных согласуются с командами DDX. [Системные требования и критерии приёмки](../sa/README.md).
