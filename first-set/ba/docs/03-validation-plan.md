# 03 · Validation plan

**Центральная гипотеза:** интерактивный онбординг повышает долю новых клиентов, фактически воспользовавшихся действующей услугой адаптации, относительно текущего сценария и простой информационной карточки.

## Как проверить проблему до разработки

- Аудит первого входа в DDX Fitness App: предлагаются ли Smart Start и ознакомительная тренировка, на каких экранах.
- Интервью с новичками и опрос об осведомлённости о вводных услугах.
- Доли записей, фактических посещений и раннего оттока по когортам.
- Ограничения расписания и пропускной способности тренеров.

## Трёхгрупповой эксперимент

| Группа | Опыт |
|---|---|
| A | Текущий онбординг |
| B | Простая карточка правил + CTA |
| C | «Первый подход» + такой же CTA |

Рандомизация на уровне пользователя до показа; сопоставимые окна наблюдения и правила доступности услуги. Размер выборки и MDE определяются после получения базовой конверсии.

## Основная метрика

Доля новых клиентов, **фактически посетивших** хотя бы одно ознакомительное занятие или Smart Start в первые 14 дней после активации подписки. Период 14 дней — гипотеза проекта, не внутренний норматив DDX.

## Промежуточные

Показ карточки → запуск → завершение станций → CTA → подтверждённая запись → фактическое посещение. Отдельно тест понимания правил и откладываемая оценка усвоения.

## Контрольные

Неявки, отмены, перегрузка вводных занятий, отказ от карточки, технические ошибки, жалобы на навязчивость.

## Долгосрочная гипотеза

Влияние на повторные посещения и сохранение подписки рассматривается отдельно; нельзя выводить его из роста игровых завершений.

## Экономическая модель

Чистый эффект = дополнительный маржинальный доход от доказанно сохранённых клиентов + подтверждённая экономия на повторяющихся вопросах − разработка − контент − поддержка − дополнительная нагрузка на вводные занятия. Подстановки без фактических данных DDX не выполняются.

## Решение об инвестициях

Переход от концепта к пилоту оправдан только после подтверждения пользовательской проблемы, возможности измерить посещения и наличия достаточной пропускной способности услуг адаптации.
