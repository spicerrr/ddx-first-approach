# 05 · Product decisions

[Кейс](../../../README.md) / [Карта артефактов](../../../NAVIGATION.md) / [BA · Бизнес-анализ](../README.md) / **05 · Product Decisions**

| ID | Решение | Основание / последствия |
|---|---|---|
| PD-01 | Игрок — посетитель, не дежурный тренер | Игра не должна выдавать освоение интерфейса за право инструктировать других |
| PD-02 | Один законченный цикл | Соответствует учебному игровому ядру и задаче первоначальной адаптации |
| PD-03 | Бесплатно для всех основных тарифов | Образовательные правила не являются инструментом upsell |
| PD-04 | CTA использует действующий Smart Start | Не дублируем запись и не создаём новую услугу |
| PD-05 | Не включаем игру в обязательное оформление членства | Клиент может отказаться; не блокируем доступ |
| PD-06 | Никаких баллов, рейтингов и платной валюты | Отделяем разовое ознакомление от будущей регулярной геймификации |
| PD-07 | Тестируем против статичного информирования | Нужно доказать добавленную ценность игры, а не одной лишь заметности CTA |
| PD-08 | 3D — прототипный вариант, а не жёсткое требование | Требует подтверждённой модели оборудования и оценки стоимости |

Все решения концептуальны и не согласованы с DDX.
