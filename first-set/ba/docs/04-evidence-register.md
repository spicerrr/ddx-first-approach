# 04 · Evidence register

| Тезис | Статус | Источник / проверка |
|---|---|---|
| У DDX есть Smart Start | Факт | [Официальная программа](https://www.ddxfitness.ru/smart-start/) |
| Приложение поддерживает запись на вводные занятия | Публичное заявление / описание | [App Store](https://apps.apple.com/ru/app/ddx-fitness/id1631792129); требуется аудит интерфейса |
| Есть правила обращения с инвентарём | Факт | [Оферта и правила](https://www.ddxfitness.ru/oferta/) |
| Клиентский поток велик | Публичное заявление | [Корпоративный портал](https://corporate.ddxfitness.ru/); дата и методика показателя требуют уточнения |
| Большинство новичков не знают о Smart Start | Не подтверждено | Опрос / продуктовая аналитика |
| Блог никто не читает | Не подтверждено | Веб-аналитика посещений и источники трафика |
| Онбординг не показывает Smart Start | Не проверено | Полный аудит экранов текущей версии |
| Игра повысит запись или посещаемость Smart Start | Гипотеза | A/B-тест |
| Игра снизит ранний churn | Отдалённая гипотеза | Эксперимент с достаточным горизонтом |
| DDX использует предлагаемые сервисы/URL/брокер | Неизвестно | Согласование с внутренней командой |

Не подменяй масштабы сети доказательством конкретного пользовательского поведения.
