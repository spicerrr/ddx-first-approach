# 02 · Business requirements

## AS-IS (упрощённая гипотетическая модель)

Покупка подписки → приложение → подготовка к визиту → первый самостоятельный визит → при желании поиск инструкций / Smart Start. Реальные экраны и способы предложения занятий требуют аудита.

## TO-BE

Покупка членства → необязательная карточка «Первый подход» → игровая сессия из четырёх этапов с разъяснением ошибок → памятка → добровольный переход в штатную запись на Smart Start / ознакомительную тренировку. Игра не создаёт запись сама.

## Бизнес-требования

| ID | Формулировка | Проверка |
|---|---|---|
| BR-01 | Игровой вход доступен как необязательная функция приложения | Возможность пропустить без ограничений клуба |
| BR-02 | Образовательный контент не закрыт тарифным paywall | Одинаковая доступность на Light, Smart, Infinity, Infinity Plus |
| BR-03 | Игрок знакомится с типовыми правилами обращения с инвентарём | Проверка сценариев и текста методистом |
| BR-04 | Ошибка объясняется и допускает повторную попытку | Негативные сценарии прохождения |
| BR-05 | Прерывание не должно приводить к потере уже принятого прогресса | Возобновление в рамках политики хранения |
| BR-06 | Игра не присваивает квалификацию и не заменяет инструктаж | Проверка текста, отсутствие формального «допуска» |
| BR-07 | После прохождения доступен маршрут к действующей программе адаптации | Системная навигация, без фиктивной брони |
| BR-08 | Разовая ознакомительная услуга предлагается только при наличии права | Проверка прав существующим контуром |
| BR-09 | События показа, старта, прохождения, клика, записи и посещения различаются | Контракты аналитики, сквозная атрибуция |
| BR-10 | Возможен контролируемый эксперимент с отключением функции | План внедрения и контрольная группа |

## Бизнес-правила

1. Подписка и реальные права клуба не изменяются по результату игры.
2. Игра добровольна и бесплатна на всех тарифах.
3. Smart Start и ознакомительная тренировка принадлежат существующим процессам DDX; ограничения проверяются там.
4. Клик по CTA не означает подтверждённое бронирование или фактический визит.
5. Игровые действия не являются доказательством готовности пользователя работать с реальным оборудованием.

## Граница MVP

Один опубликованный сценарий, четыре последовательные станции, текстовые пояснения, завершение и переход к услуге, сохранение прохождения и продуктовые события. Без наград, социальных функций, собственной записи, платежей и долгосрочной прогрессии.
